# Voll.med

Uma aplicação web para gerenciamento de clínicas médicas desenvolvida como projeto de estudos no ecossistema Spring Boot 3 e Java 17. Arquitetura MVC, segurança e persistência de dados.

## Escopo do Projeto

Durante o desenvolvimento deste projeto, pratiquei conceitos essenciais para construção de aplicações corporativas:

* **Desenvolvimento MVC:** Construção de controladores e renderização de views dinâmicas utilizando Thymeleaf.
* **Segurança:** Configuração de controle de acesso, criptografia de senhas e autenticação com Spring Security.
* **Persistência e Migrações:** Modelagem de dados com Spring Data JPA e controle de versão do banco de dados utilizando Flyway.
* **Validação de Dados:** Uso de especificações do Bean Validation para garantir a integridade das informações trafegadas em formulários.

## Tecnologias Utilizadas

* **Linguagem:** Java 17
* **Framework:** Spring Boot 3.3 (Web, Security, Data JPA, Validation)
* **Banco de Dados:** MySQL 
* **Front-end / Views:** Thymeleaf
* **Gerência de Dependências:** Maven
